# myapp
An interactive web application that automates student assessment by delivering single-choice, four-option quizzes with instant scoring to eliminate manual grading.
Interactive Quiz Interface: Displays questions with four distinct choices in a clean, user-friendly layout.

Automated Real-Time Scoring: Instantly checks answers upon submission to eliminate manual grading delays.

Single-Choice Selection Logic: Enforces strict selection rules so users can only pick one answer per question.

Immediate Performance Summary: Provides instant feedback with total scores, correct answers, and final percentages.
Frontend: HTML5, CSS3, JavaScript 

Backend: Node.js 

Database: LocalStorage / JSON file 

Deployment: GitHub Pages
